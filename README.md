# 浙江省电工高级工理论题库（在线刷题）

单文件网页：**打开就能刷题**，不需要安装、不需要账号、不联网。题库是浙江省**电工（维修电工）高级工**理论部分常见题型（单选 / 多选 / 判断），一共 **450 题**，带**错题本、按知识点分析、非错题考试、计时与答题速度、跨电脑导入导出**。

当前版本：**v5（错题增强版）**。

English: a single-file offline HTML quiz for the Zhejiang (China) **senior electrician / maintenance electrician** theory exam. 450 questions, wrong-question book in `localStorage`, print/export/import, timed practice. Open `index.html` or `电工高级工_在线考试系统_v5.html` in a browser.

---

## 1. 项目是做什么的

备考时最麻烦的不是“找到题”，而是：

- 整卷太长，想按**题型**或**知识点**拆开练；
- 错过的题下次找不到，也不知道**哪一类错得最多**；
- 已经会的题还在反复刷，浪费时间；
- 想估一下 **90 分钟**大概能做多少题；
- 家里电脑和公司电脑各练各的，错题对不上。

这个页面把题库和练习流程捆在一起：浏览器打开即用；对错当场显示；答错自动进错题本；可以只重做错题，也可以反过来**只考还没错过的题**。错题记录只存在**你自己的浏览器**里，不会上传。

题库来自原 PDF 理论题，页面里对少数明显印错的答案做了**订正**（会标「订正题」），并保留原题库答案方便对照。个别题官方答案与常见资料不一致，标了「存疑」，仍按原答案给分。

**这不是正式考试系统，也不能替代培训机构或人社部门公布的大纲。** 用来日常刷题、查漏、考前过错题。正式考试以当年通知和试卷为准。

## 2. 完整功能

### 2.1 全卷刷题

打开后默认列出**全部 450 题**，每题一张卡片：题型标签、知识点、原题号、题干、选项。

| 操作 | 行为 |
|------|------|
| 顶栏「范围」下拉 | `全部题目` / 按题型（单选 300、多选 50、判断 100）/ 按知识点（15 类，见第 4 节） |
| 「顺序 / 随机」 | 当前范围内按原题号顺序，或洗牌后练习 |
| 单选、判断 | **点选项立刻判分**，对的绿、错的红，并给出正确答案 |
| 多选 | 可点多个选项（高亮），点该题「确定」后才判分；漏选、多选都算错 |
| 判断题选项 | 界面用 √ / ×，内部仍是「正确 / 错误」 |
| 顶栏计数 | 共 / 已答 / 对 / 错 / 正确率，以及进度条（相对**当前卷**，不是永远相对 450） |
| 「重做本卷」 | 清掉当前卷的作答状态，重新做；**不会清空错题本** |
| 右下角 ↑ | 回到页面顶部 |

切换范围或顺序会退出「错题卷 / 非错题卷」模式，回到普通刷题。

### 2.2 错题本（核心）

错题记录存在浏览器 `localStorage`，键名 **`egw_wrong_v1`**。每条记录是 `{ id, ts }`：`id` 是题库内部编号 0–449，`ts` 是答错时的时间戳。同一道题多次答错会留下多条记录（用于按小时统计），去重后才是「几道错题」。

**自动收录**

- 单选 / 判断 / 多选只要判为错误，立刻写入错题本。
- 顶栏「📕 错题本 (N)」里的 **N** 是**去重后的题数**。

**手动加入 / 移出**

- 每题底部有「☆ 加入错题本」；已在本里则显示「★ 已在错题本（点此移出）」。
- 用来把「蒙对但不熟」的题钉住，或把已经会的题拿掉。

**错题本面板**（点顶栏「📕 错题本」展开）

1. **错题分析**：按知识点列出「这类错了几道」，点某一行只练该类错题。
2. **按小时分组**：同一小时内错过的题收成一格，可勾选多格（例如只复习今天下午那一拨）。
3. **加载所选错题作答**：进入「📕 错题卷」，页面上只剩这些题；不勾任何小时 = 加载**全部**错题。
4. 全选 / 全不选 / **清空错题本**（有确认，不可恢复）。

**在错题卷里**

- 横幅显示「仅含错题」，可退出回到普通卷。
- 答对后出现「✓ 已掌握，移出错题本」：从本里删掉这道题，并移出当前卷。
- 在错题卷里如果再答错，仍会再记一条记录。

**打印与搬运**

| 按钮 | 作用 |
|------|------|
| 🖨 导出打印 | 新窗口生成错题清单（题干、选项、正确答案），适合打印或另存 PDF |
| ⬇ 导出数据 | 下载 JSON：`{ version, exportedAt, records: [{id, ts}, ...] }` |
| ⬆ 导入数据 | 选 JSON。确定 = **合并**到本机（按 `id\|ts` 去重）；取消 = **覆盖**本机错题本 |

导入后自动打开错题本面板。可先在电脑 A 导出，到电脑 B 导入，再点「考非错题」，用 A 的错题集合在 B 上查漏。

清空浏览器站点数据、换浏览器、无痕窗口，都会让错题本看起来是空的——数据还在原来的配置里，并没有同步到云端。

### 2.3 考非错题（题库 − 错题本）

顶栏「✅ 考非错题」：从 450 题里去掉当前错题本中的题，专攻还没错过（或已移出本）的题。

- 显示：题库总数、错题本数、剩余可考数。
- 四个入口：全部非错题 / 仅单选 / 仅多选 / 仅判断。
- 仍尊重顶栏的「顺序 / 随机」。
- 进入后是绿色「非错题卷」横幅；在这里答错，**照样自动进错题本**。
- 建议流程：先导入或攒一批错题 → 考非错题查漏 → 再回错题本过一遍。

若错题本已经覆盖全部 450 题，会提示没有可考的非错题。

### 2.4 计时与答题速度

「▶ 开始答题」开始计时，「■ 结束答题」出统计。

- 计时**只统计按下开始之后新作答的题**（开始前已做好的不算速度）。
- 结束时给出：用时、本次作答对/错/正确率、每题分钟数与秒数、每分钟题数、每 5 分钟题数、**按该速度 90 分钟大约能做多少题**（常见理论考试时长，仅供参考）。
- 若开始后一道新题都没做，会说明无法计算速度。
- 要按整卷重新计时：先「重做本卷」，再「开始答题」。

计时状态在内存里，刷新页面会丢；错题本不受影响。

### 2.5 判分、订正与存疑

判分规则：单选 / 判断必须与标准答案字母（或「正确/错误」）完全一致；多选把所选字母排序后与标准答案比较，少选多选都错。

部分题在原 PDF 里答案有误，本页已改，卡片会标「订正题」。「已订正」时仍显示「原题库答案：…（原 PDF 题库，有误）」。另有少量「存疑」题，按原答案给分，解析里写了原因。

其中一题原选项（一/二/三/四次）全部不对（辅助继电器等触点在梯形图中可用无数次），标了「原题无正确项」，并在解析里说明。

## 3. 建议怎么练

1. **第一轮**：范围选「全部」或按「数控机床 / PLC / 机床电气」等大头知识点，顺序或随机过一遍。不会的不要猜完就走——看解析和订正说明。
2. **错题**：每天打开错题本，按知识点点进去只练弱项；会了就「已掌握，移出」。
3. **查漏**：错题本有一定数量后，用「考非错题」扫还没错过的题，新错的会自动进来。
4. **考前**：导入或合并错题 JSON，打印错题清单；用计时估 90 分钟手感。不要把本页速度当成正式考试标准。

手机浏览器可以打开，卡片是单列布局；选项要点准。数据按「浏览器 + 域名/文件来源」隔离：用 `file://` 打开和用本地静态服务器打开，错题本是两套。

## 5. 怎么运行

不需要 Node、Python 或打包。

**方式 A（最简单）**

1. 克隆或下载本仓库。
2. 用 Chrome / Edge / Firefox 打开 `index.html`（会跳到题库页），或直接打开 `电工高级工_在线考试系统_v5.html`。

**方式 B（本地静态服务，可选）**

部分浏览器对 `file://` 下的下载/打印限制更严。可在仓库根目录：

```powershell
python -m http.server 8080
```

浏览器打开 `http://127.0.0.1:8080/`。

## 6. 技术栈与数据

| 层 | 说明 |
|----|------|
| 页面 | 单个 HTML，内嵌 CSS + JavaScript，无构建步骤 |
| 题库 | 内嵌 JSON：`DATA.questions`、`DATA.topicOrder` |
| 错题 | `localStorage['egw_wrong_v1']`，JSON 数组 |
| 运行时作答 | 内存对象 `ST`（已判分）、`SEL`（多选未提交），刷新即丢 |
| 依赖 | 无 npm / CDN；字体走系统（含微软雅黑） |

导出 JSON 示例：

```json
{
  "app": "egw-wrongbook",
  "version": 1,
  "key": "egw_wrong_v1",
  "exportedAt": 1730000000000,
  "exportedAtStr": "2026/1/1 12:00:00",
  "uniqueCount": 1,
  "recordCount": 1,
  "records": [
    { "id": 12, "ts": 1730000000000 }
  ]
}
```

导入兼容：根是数组，或对象里的 `records` / `data` 数组。只保留带数字 `id` 的项。

## 8. 隐私与使用注意

- 仓库里是题目和答案，用于个人学习。不要把本机浏览器里的错题 JSON 误提交进 git（默认也不会）。
- 不要在页面或文档里填写姓名、准考证号、单位内网地址。
- 订正与存疑是学习标注，不是人社部门勘误公告。
- 刷新、换浏览器、清站点数据会丢掉未导出的错题；重要记录请用「导出数据」备份。

## 9. 从零复现

1. 用任意编辑器保存一个 HTML，结构为：顶栏筛选 + `#list` 卡片列表 + `#wrongpanel` / `#nonwrongpanel` / `#speedpanel`。
2. 将 450 题放入 `DATA.questions`（字段：`id, type, num, stem, options, answer, origAnswer, topic, corrected, note, noOpt, isTF, correctText`）。
3. 实现：筛选与随机、即时判分、`logWrong` / `wrongIds`、按小时分组与按知识点分析、错题卷、非错题池、打印 HTML、JSON 导入导出、开始/结束计时。
4. 用 `localStorage` 持久化错题；用内存保存当次作答。无需后端。
